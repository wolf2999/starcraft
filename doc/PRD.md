## 1. 产品概述

### 1.1 一句话定位
一款在浏览器中运行的、星际争霸 1 风格的即时战略（RTS）Demo：三族混战、采集-建造-爆兵-推平的经典循环，开箱即玩、零版权素材。

### 1.2 背景与目标
- 星际争霸 1 原版素材受暴雪版权保护，不可直接分发；本项目以**程序化生成 + AI 出图**的方式自产全部素材，无任何版权风险。
- 技术验证目标：跑通 Phaser 4 + TypeScript + Vite 做等距 2D RTS 的完整链路（大地图渲染、寻路、多阵营 AI、生产/科技/技能体系）。

### 1.3 目标用户
- 怀旧 RTS 玩家：想在工作间隙来一局 10 分钟的星际。
- 前端/游戏开发者：参考一个"小而全"的 Phaser 4 RTS 实现范本。

### 1.4 平台与运行环境
| 项 | 要求 |
|---|---|
| 浏览器 | Chrome / Edge 现代版（WebGL + Web Audio） |
| 运行 | `npm run dev` 开发服（localhost:5173）或 `npm run build` 静态部署 |
| 依赖 | Node 18+；运行时仅 Phaser 4.0.0，无后端 |
| 分辨率 | RESIZE 自适应，桌面键鼠为主 |

## 2. 核心玩法循环

```
采集（矿/瓦斯）→ 建造（人口/产能/科技建筑）→ 生产（单位/升级）
    ↑                                        ↓
    └────── 补农民/扩矿区 ←── 战斗（推平对方阵营即胜）
```

一局的标准体验（10~20 分钟）：
1. **开局**：主菜单选敌人数（1~3），玩家与 AI 随机分到 Lost Temple 四角出生点。
2. **经济期**：框选 SCV 采集水晶矿/瓦斯，补农民、造供给站。
3. **建造期**：农民 B 键打开建造面板 → 幽灵放置 → 施工状态机；解锁产能建筑与科技建筑。
4. **爆兵期**：左键点建筑 → 底部训练面板点按钮下单（含变异/研究三类按钮共板）；虫族经幼虫变异孵化。
5. **战斗期**：A 攻击移动 / 右键点杀，运用技能（兴奋剂、攻城、锁隐、核弹、风暴等）。
6. **终局**：玩家全灭=失败；开局快照的全部 AI 阵营全灭=胜利，中央横幅结算。

## 3. 功能规格

### 3.1 主菜单与对局设置（P0，已上线）
- 深空星幕 + 斜切金属按钮的 SC1 风主菜单。
- 敌人数量 1/2/3（快捷键 1/2/3 + 回车开始）；地图当前仅 Lost Temple；出生点四角随机（Fisher-Yates）。
- 场景链 menu→game 经 scene data 传参；跨局状态全量重置，防上一局残留误判胜负。

### 3.2 三族与实体规模（P0，已实现）
| 阵营 | 建筑 | 单位 | 特色机制 |
|---|---|---|---|
| 人族 Terran | 20 | 13 | 施工建造、附属建筑挂接、SCV 修理、碉堡进驻、兴奋剂、攻城模式、大和炮、核弹、隐形 |
| 神族 Protoss | 12 | 15 | 护盾（先扣盾+再生）、恒隐形、灵能风暴、精神控制、航母拦截机机库 |
| 虫族 Zerg | 16 | 13 | 幼虫变异孵化+再生、建筑形态变异链（hatchery→lair→hive 等）、菌毯、自爆蚊 |
| 中立 | — | 矿/瓦斯气泉 2 | 资源节点 |

数值全部集中在 `src/config.ts` 的 `Def` 定义（见单位与建筑手册）。

### 3.3 通用系统（P0，全部已实现）
| 系统 | 规格 |
|---|---|
| 选择 | 左键点选（最近者优先）/拖框框选；Ctrl+1~9 编队保存/选回/双击居中 |
| 指令 | 右键移动/攻击/采集/装载/修理/进驻；A+左键攻击移动；ESC 取消 |
| 移动 | A* 网格寻路（地面绕水面/悬崖/虚空），空军直线 |
| 战斗 | 对地/对空伤害区分、射程/攻速/主动索敌、待命自动反击、攻击移动途中索敌 |
| 采集 | 右键矿/气泉采集循环（采 1.5s、每次入账 8）；瓦斯暂无精炼厂前置（简化） |
| 人口 | 建筑与领主供给；训练队列排队预留；HUD 实时显示 |
| 生产 | 训练队列（校验资源/人口/科技→扣费入队→完成出场）；reactor 双倍速度 |
| 科技 | academy/ebay/armory/forge/evolutionChamber 攻/防各 3 级（+2 攻/−1 防每级） |
| 能量 | 通用能量系统（回能+蓝色能量条），驱动大和炮/锁定/核弹/风暴/精神控制 |
| 隐形体系 | 天生隐形/攻击显形 2s/恒隐形；侦测塔+侦测单位组成 7 格侦测网；己方隐形半透明 |
| 战争迷雾 | 三态（未探索/已探索/可见，仅玩家视角）；敌方实体迷雾外隐藏；小地图同步 |
| 特效 | 弹道线+命中爆点、死亡红光/建筑碎裂、技能特效（光柱/闪电/爆闪） |
| 胜负 | 1s 节流存活扫描；玩家全灭负/全部 AI 阵营灭则胜；AI 随终局停摆 |

### 3.4 AI（P0，已上线）
- 每 1.2s 错峰 tick 的分阵营决策循环：空闲农民采集 → 补供给 → 补农民（目标 8）→ 产能建筑 → 按种族偏好表出兵。
- `AI_AGGRESSIVE`：新出战斗单位自动索敌（农民除外）。
- AI 与玩家共用 `tryTrain`/建造校验管线；资源/人口按 owner 分桶互不干扰。

### 3.5 操作一览（P0）
| 输入 | 功能 |
|---|---|
| 左键/拖框 | 点选/框选 |
| 右键 | 移动/攻击/采集/装载/修理/进驻（情境化） |
| A + 左键 | 攻击移动 |
| B（农民选中） | 建造面板（幽灵放置） |
| 点建筑 | 训练/变异/研究面板 |
| T / E / Y / L / N / S / C / M / U | 兴奋剂 / 攻城 / 大和炮 / 锁定 / 核弹 / 风暴 / 精神控制 / 布雷 / 卸载 |
| Ctrl+1~9 / 数字键 / 双击 | 编队保存/选回/相机居中 |
| ESC | 取消瞄准/放置 |

### 3.6 美术与资源管线（P1，进行中）
- **程序化兜底**：所有实体有程序化像素贴图（三族风格化），零素材可跑。
- **AI 出图管线**：`art-src/ai-src/<race>/<tex>/<动作>/NN.png`（允许稀疏帧号）→ `gen-ase.mjs v3` 归一化注入；缺号以最近帧+动作变换补齐；无 ai-src 的实体与旧版逐字节一致。
- **LibreSprite 工程**：`art-src/libresprite/`（三族 89 个 .ase，单层、全画布帧、idle/walk/attack/death 或 idle/build/death tag 分组）；配套工具 `art-src/tools/`（ase_dump 结构侦查 / ase_anim 位移动画 / ase_fx 像素特效 / ase_preview 帧预览）。
- **帧规格**：小单位 80×60 / 大单位 112×84 / 建筑 144×144 或 272×272；横条 spritesheet + .ase 工程 + animDefs.json 三份产出自动对齐。

### 3.7 调试工具（P1）
- Phaser Inspector DevTools 扩展（`debug/extension/`）：注入 `window.__GAME__` 后在 DevTools 面板审查场景树/坐标/depth/显隐/层级，支持多选批量操作（仅 Phaser 4）。

## 4. 项目架构

### 4.1 技术栈
| 层 | 选型 | 说明 |
|---|---|---|
| 引擎 | Phaser 4.0.0（ESM） | 只有命名导出，统一 `import * as Phaser` |
| 语言 | TypeScript | es2020 目标，sourcemap |
| 构建 | Vite | 端口 5273；phaser alias 到 UMD 构建以兼容 liquidphaser 的 default 导入 |
| UI 库 | liquidphaser | 训练面板/HUD 的 Liquid UI 组件（需 pinLiquidUI 处理点击命中） |
| 运行时依赖 | 无后端、无数据库 | 纯前端单机，资源全部运行时生成或打包在 public/ |

### 4.2 目录结构
```
starcraft/
├── src/                    # 游戏源码
│   ├── main.ts             # 入口：场景链 [MenuScene, GameScene]、DEV 下挂 window.__GAME__
│   ├── config.ts           # 全部 Def 数据定义（三族 91 个实体数值）、全局常量
│   ├── entities.ts         # Entity 行为内核：移动/战斗/采集/建造/技能/隐形/死亡状态机
│   ├── scenes/
│   │   ├── MenuScene.ts    # 主菜单（对局设置 → scene.start 传 enemies）
│   │   └── GameScene.ts    # 主场景：输入/生产/AI/迷雾/胜负/特效/面板等系统层
│   ├── ui/liquidHud.ts     # Liquid UI 挂载（HUD/训练面板/提示）
│   ├── maps/lostTemple.ts  # 地图数据：地形、出生点、矿区、buildBases 随机布局
│   ├── terrain.ts / tilemap.ts / iso.ts   # 等距坐标换算、地形定义、逐格铺贴（不用 TilemapLayer）
│   ├── pathfinding.ts      # A* 网格寻路
│   ├── Textures.ts         # 程序化像素纹理生成（兜底素材）
│   ├── animDefs.ts/.json   # 动画帧定义（与 art-src 管线产物对齐）
│   └── minimap.ts          # 小地图（含迷雾烘焙）
├── public/
│   ├── maps/               # lost-temple.tmj（Tiled）+ terrain.png
│   └── textures/           # 生成的横条 spritesheet 贴图
├── scripts/                # gen-tileset.mjs / gen-map.mjs（地形图生成链）
├── art-src/                # 美术源管线（见 3.6 节）
│   ├── ai-src/             # AI 出图（按 race/tex/动作/帧号 组织）
│   ├── libresprite/        # 三族 89 个 .ase 工程文件
│   └── tools/              # ase_dump / ase_anim / ase_fx / ase_preview
├── debug/extension/        # Phaser Inspector DevTools 扩展
└── doc/                    # 本文档及其余设计文档
```

### 4.3 分层架构（运行时）
```
输入层  GameScene 指针/键盘 → 指令化（orderMove/Attack/…/tryTrain/tryMorph）
  ↓
数据层  config.ts Def（静态数值） + Entity 实例字段（动态状态机）
  ↓
行为层  entities.ts 内核（updateCombat/Gather/Build/Transport/Heal… 状态机）
        + GameScene 系统循环（updateAI/Interceptors/Garrison/Nuke/Fog/Victory…）
  ↓
表现层  Tilemap 逐格铺贴 + Entity Container 渲染（depth=1000+x+y 等距排序）
        + liquidHud UI + minimap + 特效 Graphics（shot/death/fx）
```
设计约定：
- **数据驱动**：种族差异尽量落在 `Def` 字段（cloaked/detects/cargoCapacity/interceptorBay…），代码只写通用机制。
- **玩家/AI 共用管线**：`tryTrain`/`canPlaceAt` 等校验同一份，AI 只是另一个 owner。
- **表现与判定分离**：战争迷雾仅作用于表现与选取层，不修改战斗数值。
- **跨局隔离**：场景实例复用，`init` 时 `resetGameState` 全量清场。

### 4.4 素材构建链
```
art-src/ai-src/（关键帧 PNG）──┐
程序化生成（Textures.ts）──────┼→ scripts/gen-ase.mjs → public/textures 横条
art-src/libresprite/（.ase）──┘        + .ase 工程 + animDefs.json
scripts/gen-tileset.mjs / gen-map.mjs → public/maps/（terrain.png + lost-temple.tmj）
```
改美术源后重跑对应脚本 + `npm run build` 同步 dist；未知名/缺目录自动回退程序化兜底，保证"零素材可跑"。

## 5. 非目标（本期不做）

- **多人联机/存档**：单机 vs AI 为限。
- **原版素材导入**：出于版权考虑永不打包暴雪素材（用户可自备替换至 `public/assets/`）。
- **种族特色依赖链**：pylon 供能、精炼厂瓦斯前置、菌毯蔓延/建筑依赖菌毯——均按简化处理不做。
- **潜地（burrow）**、虫族提速科技、细分升级树（射程/肾上腺等）——只做通用攻防研究。
- **移动端触控**：键鼠操作为前提。

## 6. 验收标准

1. **可玩性**：`npm run dev` 打开 → 主菜单 → 任选 1~3 敌人完整打完一局并出胜负横幅，全程无控制台报错。
2. **三族完整**：三族单位/建筑按"单位与建筑手册"数值可生产、可战斗；种族特色机制（护盾/幼虫/变异/隐形）生效。
3. **AI 有对抗性**：AI 能独立完成采集→建造→爆兵→进攻闭环（20s 内可见矿增长与出兵）。
4. **性能**：8 阵营混战规模下 60fps 流畅、迷雾/寻路无卡顿感。
5. **素材零版权**：仓库内不含任何暴雪素材；全部贴图可由脚本确定性重生成。
