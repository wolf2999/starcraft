# 星海争霸 Web Demo — 操作指南

一个基于 Phaser 4 + TypeScript 的即时战略（RTS）演示，包含人族（Terran）、神族（Protoss）、虫族（Zerg）三族单位与建筑、采集、战斗、AI 经济与战争迷雾。逻辑数据驱动，分三层：`src/config.ts`（兵种/建筑数据）+ `src/entities.ts`（行为内核）+ `src/scenes/GameScene.ts`（指令与系统层）。

---

## 1. 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器（Vite，固定端口），浏览器打开 http://localhost:5273
npm run build      # 生产构建（输出到 dist/）
```

## 2. 视角与地图

- 等距（isometric）视角，Lost Temple 风格大地图（128×128 格）：高低地、悬崖、坡道、水面与桥梁。地面单位走 A* 寻路自动绕开水面/悬崖，空军直线飞行。
- **滚屏**：按住鼠标中键拖动，或使用方向键；窗口大小变化时视野与缩放自适应。
- **小地图**（右上角）：点击跳转、按住拖动连续平移视野，同步渲染迷雾与实体点。
- **战争迷雾**（仅玩家视角，纯表现层，不影响战斗判定）：未探索区域纯黑、已探索但视野外暗化、视野内正常；迷雾外的敌人隐藏且不可被点选/指定；探开过的区域保留暗色记忆。

## 3. 通用操作（三族通用）

| 操作 | 效果 |
| --- | --- |
| **左键拖拽框选** | 框选范围内己方单位（建筑不参与框选，只能点选） |
| **左键点选** | 选中单个单位 / 建筑；选中可训练建筑自动弹出训练/研究面板 |
| **左键点空地** | 已有选区时下达移动指令；无选区则清空选区 |
| **右键点空地** | 选中单位移动到该点 |
| **右键点资源（矿物/气泉）** | 农民前往采集，自动往返（**瓦斯无需精炼厂，简化**） |
| **右键点敌方单位/建筑** | 可攻击单位直接锁定攻击（迷雾外敌人不可指定） |
| **右键点己方受伤机械/建筑** | SCV 修理（35 HP/秒，满血自动收工；虫族农民不能修理） |
| **右键点己方地面单位** | 运输机装载（dropship/shuttle/领主，容量够即前往装载） |
| **右键点己方碉堡** | 步兵前往进驻（marine/firebat/medic/ghost/scv，容量 4） |
| **右键点未完工建筑** | 农民继续施工 |
| **A 键 + 左键点地** | 攻击移动（A-Move）：前进途中自动攻击遇到的敌人 |
| **B 键** | 选中农民开/关建造面板（SCV/探针/工蜂通用） |
| **Ctrl+1~9** | 保存当前选区为编队 |
| **1~9** | 召回编队（自动过滤已死亡成员）；400ms 内双击同键相机居中编队 |
| **U 键** | 卸载：选中运输机环形落位乘客 / 选中碉堡卸出驻兵 |
| **ESC** | 取消建造放置 / 攻击移动 / 技能瞄准态，关闭面板 |
| **中键拖动 / 方向键** | 滚动相机 |

- 屏幕底部 HUD 显示：矿物 / 瓦斯 / 人口(已用/上限) / 实体总数 / 当前选中数；最底部一行提示常用操作。
- **训练面板**：买不起、科技不满足（前置建筑未建成）时按钮置灰；队列上限 5，排队即预留人口；建筑被摧毁时队列中已扣费项目**自动全额退款**。
- **建造面板**：显示建筑名 + 矿价，买不起/前置不满足置灰；幽灵建筑跟随鼠标吸附格子，实时红绿显示合法性（地形 / 高差 / 重叠 / 精炼厂绑气泉 / 附属绑主建筑），左键落子、右键取消。

## 4. 三族特有操作

### 人族（Terran）
- **农民 = SCV**：右键资源采集；B 键建造面板放置建筑，SCV 前往施工（半透明地基 + 进度条，HP 随施工从 10% 增长至满值）；右键己方受伤机械单位/建筑进行修理。
- **附属建筑**：四附属均由 SCV 建造，必须建在主建筑 2.2 格内、每主建筑同类限一座（星际式贴建）——
  - **卫星站**（挂指挥中心）：反隐形侦测；
  - **核弹井**（挂指挥中心）：解锁 ghost 核弹（N 键）；
  - **科技实验室**（挂兵营）：解锁 ghost 训练；
  - **反应堆**（挂兵营）：训练速度 ×2。
- **碉堡**：步兵右键进驻（容量 4），驻兵聚合开火（伤害求和、射程 +32px），U 键卸载；碉堡被毁驻兵陪葬。
- **单位技能**：坦克 E 切攻城模式（60 伤 / 12 格射程，展开后不能移动）；机枪兵/喷火兵 T 兴奋剂（自伤 10 HP，攻速/移速 +50% 持续 15s）；雷车 M 脚下布雷（携 3 颗不补充，敌触即爆 100 伤 AoE）；ghost 天生隐形（攻击显形 2s）、L 锁定敌方机械单位 60s（耗能 100）、N 核弹（需核弹井，10s 引导、600 伤 3 格溅射敌我通吃、30s 全局装填）；战列巡洋舰 Y 大和炮（250 伤穿透护盾，耗能 150）；medic 空闲自动治疗 6 格内受伤友军；导弹塔/科学球反隐形侦测。
- **运输机 dropship**：容量 8，右键己方地面单位装载、U 键卸载。
- **科技研究**：研究院/工程湾/军械库选中弹研究按钮，攻击/防御升级各 3 级（见第 5 节）。

### 神族（Protoss）
- **农民 = 探针**：右键资源采集，B 键建造。
- **护盾机制**：所有神族单位/建筑拥有护盾（蓝条），受伤**先扣护盾再扣血**；脱战后护盾缓慢自动恢复。
- **单位技能**：高阶圣堂 S 灵能风暴（耗能 75，3 波 ×20 伤 AoE，敌我通吃，不伤建筑）；黑暗圣堂恒隐形（攻击不显形）；黑暗执政官 C 精神控制（耗能 150，永久策反 1.5 格内敌方单位）；航母机库 8 架拦截机自动出击/回收、选中航母可免费补造；观察者隐形 + 反隐形侦测。
- **运输机 shuttle**：操作同 dropship（容量 8）。
- **科技研究**：锻造炉攻/防研究。
- **光子炮台**：对地对空 + 反隐形侦测。

### 虫族（Zerg）
- **工蜂 drone**：右键资源采集，B 键建造（SCV 式施工放置，非消耗变异）。
- **幼虫孵化**：孵化场/巢穴/母巢的训练面板列出全部虫族兵种，训练即消耗一只附着幼虫；幼虫每 12s 再生 1 只（每基地 ≤3 只）。
- **变异链**：孵化场 → 巢穴 → 母巢；飞龙塔 → 大飞龙塔；菌毯殖民地 → **地刺堡（对地）** 或 **孢子堡（对空+反隐）**——面板选择，原位替换并保留当前 HP。
- **领主 overlord**：+8 人口、反隐形侦测、可装载 8 位（操作同 dropship）。
- **自爆蚊 scourge**：撞近空中目标即自爆（110 伤，自身同亡）。
- **菌毯**：虫族建筑周围铺展菌毯（视觉层，不强制建造位置）；尼达斯坑道为占位演示建筑（不实现传送）。

## 5. 战斗说明

- **索敌**：双方单位待命时自动迎击视野（6 格）内的敌人（星际式"驻守迎击"），目标死亡即回待命；受击自动反击（农民除外，打完这波即停）。AI 主动进攻单位会全图索敌。手动指令优先于自动索敌。
- **对空 / 对地**：每个攻击单位有 `attackType`（`ground`/`air`/`both`）。例如飞龙可对空对地，女武神仅对空，坦克仅对地。无法攻击的目标不会被选为攻击对象。
- **攻击间隔**：每次开火后进入冷却（`attackInterval` 毫秒），期间不能再次开火。
- **隐形 / 反隐形**：ghost/隐飞天生隐形（攻击瞬间显形 2s），黑暗圣堂/观察者恒隐形；己方隐形单位半透明可见。侦测单位/建筑（导弹塔/孢子堡/光子炮/卫星站/科学球/领主/观察者）7 格内解锁敌方隐形单位的锁定与攻击；隐形单位攻击被侦测者时暴露自身。
- **能量**：ghost/科学球/战列巡洋舰/高阶圣堂/黑暗执政官有能量条（蓝色），每秒回复 1 点，供各技能消耗。
- **科技升级**：攻击升级每级 +2 伤害、防御升级每级 -1 受伤（全兵种通用，攻防各自 3 级）。
- **伤害与死亡**：伤害先扣护盾（神族）再扣血；HP 归零单位/建筑死亡并播放碎裂特效；**建筑死亡时训练队列按造价全额退款**。
- **AI 与胜负**：AI 阵营各自采集、补农、建造、出兵并主动进攻，三阵营互为敌对（FFA 混战）；玩家全灭 = 失败、全部 AI 阵营全灭 = 胜利，中央横幅提示后 AI 停摆（仍可自由观察战场）。
- **人口**：训练单位消耗人口（`supply`），由供给站 / 水晶塔 / 孵化场系 / 领主 提供上限。

## 6. 演示初始阵容（Lost Temple）

- **玩家（左下）**：人族指挥中心 + SCV×3 + 机枪兵×2，起手 50 矿。
- **ai1（左上）**：虫族孵化场 + 工蜂×3 + 小狗×2。
- **ai2（右下）**：神族枢纽 + 水晶塔 + 探针×2 + 狂徒 + 龙骑士。

开局后 AI 会自主发展经济并出兵进攻，可直接观察三族混战；将某一阵营全灭（或生存至 AI 互相消耗殆尽）可观察胜负横幅。
