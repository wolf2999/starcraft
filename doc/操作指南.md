# 星海争霸 Web Demo — 操作指南

一个基于 Phaser 4 + TypeScript 的即时战略（RTS）演示，包含人族（Terran）、神族（Protoss）、虫族（Zerg）三族单位、建筑、采集与战斗系统。所有逻辑数据驱动，集中在 `src/config.ts`。

---

## 1. 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器（Vite），浏览器打开提示的地址
npm run build      # 生产构建（输出到 dist/）
```

---

## 2. 视角与地图

- 固定俯视视角，地图无滚动（1280×720 单屏）。
- 左下角绿色方块为地面，蓝色晶体为矿物，绿色气泉为瓦斯。
- 地图下半部分有一条紫色斑驳区域为**虫族菌毯**（视觉层，仅虫族建筑需要建在其上方，本演示不强制校验位置）。

---

## 3. 通用操作（三族通用）

| 操作 | 效果 |
| --- | --- |
| **左键拖拽框选** | 框选范围内己方地面单位 |
| **左键点选** | 选中单个单位 / 建筑（建筑显示右侧生产面板） |
| **右键点空地** | 选中单位移动到该点 |
| **右键点资源（矿物/气泉）** | 选中农民前往采集（工蜂/探针/SCV 自动往返） |
| **右键点敌方单位/建筑** | 选中可攻击单位直接锁定攻击该目标 |
| **A 键 + 左键点地** | 攻击移动（A-Move）：单位前进并在途中自动攻击遇到的敌人 |
| **ESC** | 取消建造放置 / 取消攻击移动模式 |
| **点选建筑后右侧面板** | 点击面板中的条目训练单位或建造附属/升级建筑 |

- 屏幕底部 HUD 显示：矿物 / 瓦斯 / 人口(已用/上限) / 单位数 / 建筑数 / 当前选中数。
- 屏幕最底部一行提示当前可用操作。

## 4. 三族特有操作

### 人族（Terran）
- **农民 = SCV**：右键资源采集；选中后从面板造建筑，建筑以“放下后展开建造”动画出现。
- **供给站**：可降下/收起（演示中保留供能，不实现升降交互）。
- **建筑生产**：点选兵营/飞机场等，右侧面板点兵种训练；训练完成后单位从建筑周围“飞入/走出”。
- **附属建筑**：指挥中心可造卫星站、核弹井（仅数据，无实际技能）；兵营/工程湾等可造附属。

### 神族（Protoss）
- **农民 = 探针**：同样右键资源采集。
- **护盾机制**：所有神族单位/建筑拥有护盾（蓝条），受伤**先扣护盾再扣血**；脱战后护盾缓慢自动恢复。
- **水晶塔供能**：本演示不强制“无供能断电”校验，但水晶塔提供 +8 人口。
- **建筑生产**：点选枢纽/兵营/星门等，右侧面板训练单位。

### 虫族（Zerg）
- **工蜂变建筑**：工蜂（drone）选中后从面板选择建筑，放置即“变形”为建筑（演示中简化为直接生成建筑体，工蜂仍保留）。
- **菌毯**：虫族建筑需建在菌毯上（演示仅视觉展示，不强制）。
- **幼虫孵化**：孵化场持续产出**幼虫（larva）**；所有虫族兵种都从幼虫孵化（本演示简化为直接训练）。
- **主基地升级链**：孵化场 →（变异）巢穴 →（变异）母巢；飞龙塔 →（变异）大飞龙塔。点选主基地/飞龙塔，面板中会出现升级项，点击后**原位替换**为升级形态建筑。
- **菌毯殖民地**：可升级为**地刺堡（对地）** 或 **孢子堡（防空+反隐）**。
- **尼达斯坑道**：演示建筑，作为两基地间传送通道的占位（本演示不实现实际传送）。

## 5. 战斗说明

- **索敌**：敌方战斗单位默认主动寻找并攻击进入射程的玩家单位；玩家单位需通过右键攻击或 A-Move 主动交战。
- **对空 / 对地**：每个攻击单位有 `attackType`（`ground`/`air`/`both`）。例如飞龙可对空对地，女武神仅对空，坦克仅对地。无法攻击的目标不会被选为攻击对象。
- **攻击间隔**：每次开火后进入冷却（`attackInterval` 毫秒），期间不能再次开火。
- **伤害与死亡**：伤害先扣护盾（神族）再扣血；HP 归零单位死亡并播放碎裂特效，从场景移除。
- **攻击特效**：开火时在攻击者与目标间绘制弹道线，命中处出现火花。
- **人口**：训练单位消耗人口（`supply`），由供给站 / 水晶塔 / 孵化场 / 领主 提供上限。

## 6. 演示初始阵容（便于快速观察战斗）

- **玩家（左/中）**：人族指挥中心 + SCV×4 + 机枪兵×3 + 坦克；虫族孵化场 + 小狗×2 + 刺蛇 + 飞龙 + 守护者 + 自杀蚊。
- **敌方（右）**：人族指挥中心 + 机枪兵×3 + 坦克；神族水晶塔 + 狂徒 + 龙骑士 + 海盗船 + 执政官。

开局后敌方单位会自动进攻，可直接观察三族混战。
