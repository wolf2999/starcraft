草地（1）：绿色菱形 + 草簇散点
高地（2）：土黄菱形顶面 + 下缘 16px 侧面带（表现抬升）
斜坡（3）：上草下土过渡 + 半高侧面
水面（4）：蓝色菱形 + 波纹
桥（5）：木色菱形 + 木板缝 + 侧面带
虚空（gid 0）：有效区之外的格子，不渲染、不可通行

地图规格：
- 等距投影（2:1 菱形），tile 顶面 64×32，1 格逻辑边长 = 64px（见 src/iso.ts）。
- 数据网格 128×128 格；有效格排成一条对角带（u = gx+gy ∈ [64,194]，
  v = gx-gy ∈ [-32,32]，即 iso.ts 的 U_MIN/U_MAX/V_MIN/V_MAX），带外为 void 虚空。
- 等距投影下世界轴对齐矩形必然投成 2:1 菱形；要让屏幕轮廓呈正方形，有效区
  必须是对角带且 U 跨度 = 2 × V 跨度 ⇒ 地图轮廓为 2048×2080 的近似正方形
  （MAP_LEFT=0、MAP_TOP=16、MAP_W=2048、MAP_H=2080）。
  注意：菱形网格沿 45° 方向的边界天然是锯齿形；渲染用格中心 (+0.5) 导致顶行
  锯齿谷线在 sy=HALF_H，故 MAP_TOP=HALF_H；锯齿带完全落在边界矩形之外，
  相机看不到。
- 每级地形高度抬升 ELEV=16px：高地/斜坡顶面渲染时上移 h*ELEV，侧面带垂回地面格位。
- tileset 单帧 64×64（顶面菱形 + 侧面带 + 余量），terrain.png 为 320×64 横排 5 帧。
- 出血位为 0（MAP_BLEED 恒 0）：相机拖动边界直接贴谷线矩形
  （setBounds(MAP_LEFT, MAP_TOP, MAP_W, MAP_H)），拖到极限时视口边缘 = 地图边缘，
  视口内永远看不到地图外黑边；开局视野同样夹在地图范围内。
  出血位无需随“撑满浏览器”调整——撑满由画布模式 + 动态缩放下限保证。
- 画布撑满浏览器：Phaser Scale 模式为 RESIZE（src/main.ts），画布 = 浏览器窗口
  实际大小（无 FIT 信箱黑边）；src/scenes/GameScene.ts 监听 scale resize 事件，
  同步缩放下限并夹紧视野，任意窗口尺寸下视口都完全落在地图内。
- 滚轮缩放下限 minZoom(视口宽, 视口高) = max(视口宽/地图宽, 视口高/地图高)
  （src/iso.ts，按实际画布尺寸动态计算，非固定常量），缩到最小时视口仍完全
  落在地图包围盒内，同样不露黑边；窗口宽于地图（>2048px）时下限 > 1，
  相机自动放大以撑满地图。
- 数据源：public/maps/lost-temple.tmj（等距地图）+ public/maps/terrain.png，
  由 scripts/gen-map.mjs / scripts/gen-tileset.mjs 程序化生成（无外部美术依赖），
  改图后重跑即可；真美术按同规格出图直接覆盖 terrain.png。
  地形格子布局在 gen-map.mjs 与 src/maps/lostTemple.ts 两处保持同步
  （出生点/矿区以 lostTemple.ts 为准）。
- 注：.tmj 声明 tileheight=32（菱形高），图集帧高 64 含侧带，Tiled 打开时帧对位
  会偏，但不影响本项目（渲染由 src/tilemap.ts 自行投影铺贴，不经 Tiled 帧切割）。
