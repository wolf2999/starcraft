# 星海争霸 Web Demo — 单位与建筑手册（含战斗数值配置）

> 本文件记录三族全部已实现建筑与兵种，以及战斗相关数值配置。
> 所有数值均来自 `src/config.ts` 中的 `Def` 数据定义，可直接对照修改。
> 字段含义：
> - **矿物 / 瓦斯**：建造/训练造价
> - **人口**：单位占用的人口（建筑为提供人口用 `supplyProvided`）
> - **耗时**：建造/训练毫秒
> - **HP / 护盾**：生命值 / 神族护盾（护盾不致死，优先被扣且自动恢复）
> - **对地/对空**：攻击力（`groundDamage` / `airDamage`，未标注即 0/无）
> - **类型**：可攻击目标 `ground`(仅对地) / `air`(仅对空) / `both`(均可)
> - **射程**：像素
> - **攻速**：攻击间隔毫秒
> - **速度**：移动速度 像素/秒（`空中` 标注为飞行单位）

## 四、战斗数值配置规则说明

战斗相关字段均定义在 `src/config.ts` 的 `Def` 接口中：

| 字段 | 含义 | 备注 |
| --- | --- | --- |
| `groundDamage` / `airDamage` | 对地 / 对空攻击力 | 取目标是否为空中决定用哪个值 |
| `attackType` | `ground` \| `air` \| `both` | 决定能否选中空中/地面目标 |
| `range` | 射程（像素） | 进入射程才开火 |
| `attackInterval` | 攻击间隔（毫秒） | 开火后冷却，期间不可再攻击 |
| `speed` | 移动速度（像素/秒） | 0 表示不可移动（如幼虫、部分建筑） |
| `air` | 是否空中单位 | 影响被索敌（仅对空/对空对地单位能打它） |
| `shield` | 神族护盾值 | 与 `hp` 并存；受伤先扣护盾；`Entity.takeDamage` 实现；护盾在 `GameScene.update` 中按 `maxShield` 比例缓慢恢复 |

**索敌与开火流程**（`src/entities.ts`）：
1. `acquireTarget(pool)`：在所有存活实体中找最近的、阵营不同且 `canAttackTarget` 成立的敌人。
2. `canAttackTarget(target)`：依据攻击者 `attackType` 与目标 `isAir` 判断是否可命中。
3. `updateCombat(dt)`：在射程内且冷却结束则 `fire()`；不在射程内则单位自动接近。
4. `fire()`：按目标类型取伤害 → `takeDamage()` → 触发 `onAttack` 弹道特效。

**死亡处理**：`takeDamage` 使 `hp<=0` 时 `alive=false`；`GameScene.update` 每帧清理死亡实体并播放碎裂特效。

> 如需调整平衡，直接修改 `src/config.ts` 中对应 `Def` 的数值即可，无需改动战斗逻辑代码。
