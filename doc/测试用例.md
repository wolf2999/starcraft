# 星海争霸 Web Demo — 测试用例

> 适用版本：与《开发进度.md》《操作指南.md》同步。
> 测试方式：浏览器手动测试（`npm run dev` 后打开 http://localhost:5273）+ 可选控制台断言。
> 优先级：P0 = 核心流程（阻断级）/ P1 = 主要功能 / P2 = 边缘与体验。
> 每条用例包含：前置条件、操作步骤、预期结果。实际结果与结论（通过/失败）由测试人填写。

---

## 1. 主菜单（MenuScene）

### TC-M01 启动进入主菜单 【P0】
- **前置**：`npm run dev` 正常启动，无缓存报错。
- **步骤**：浏览器打开 http://localhost:5273。
- **预期**：显示深空星幕主菜单；标题、副标、对局设置面板（敌人数量/种族/地图信息）、开始按钮完整渲染；控制台无报错。

### TC-M02 敌人数量选择（鼠标） 【P0】
- **步骤**：依次点击「1 个敌人 / 2 个敌人 / 3 个敌人」。
- **预期**：点击的按钮琥珀描边 + 指示三角；下方说明文字随选择切换（双人对决 / 三足鼎立 / 四角混战）；互斥选中。

### TC-M03 敌人数量选择（快捷键） 【P1】
- **步骤**：按键盘 `1` / `2` / `3`。
- **预期**：与鼠标点击效果一致。

### TC-M04 种族选择（鼠标 + 快捷键） 【P0】
- **步骤**：依次点击「人族 / 神族 / 虫族」按钮；再用 `Q` / `W` / `E` 切换。
- **预期**：选中态互斥；种族说明文字随选择切换（人族机械化 / 神族护盾科技 / 虫族数量压制）；两种输入路径效果一致。

### TC-M05 开始游戏进入对局 【P0】
- **前置**：选择敌人数量 2、种族人族。
- **步骤**：点击「开始游戏」或按回车。
- **预期**：切换到游戏场景；相机对准玩家出生点（四角之一）；HUD 显示矿物 50；玩家阵营为所选种族（主基地/农民/初始兵匹配）。

### TC-M06 出身点随机分配 【P1】
- **步骤**：连续开 3 局（游戏结束后回菜单再开），记录玩家与 AI 出生角落。
- **预期**：每局出生角落随机变化；玩家 + 前 N 个 AI 占用不同角落；未占用角落保留矿区。

### TC-M07 菜单↔游戏往返无状态泄漏 【P0】
- **步骤**：开 3 敌局 → 回菜单 → 开 1 敌局。
- **预期**：第二局仅 1 个 AI 阵营（可开控制台查 `resBy`/`aiOwners`）；无上一局残留单位/资源；胜负判定正常（不会开局即胜利）。

### TC-M08 窗口缩放自适应 【P2】
- **步骤**：在菜单界面拖拽改变浏览器窗口大小。
- **预期**：菜单整体居中重排，按钮可正常点击（命中区跟随），无重叠/溢出。

## 2. 多语言（i18n）

### TC-L01 系统语言自动检测 【P0】
- **步骤**：将浏览器/系统语言分别设为简体中文、繁体中文、英文、其它语言（如日语/法语），刷新页面。
- **预期**：简中环境 → 全部文案简中；繁中环境（zh-TW/zh-HK/zh-MO/zh-Hant）→ 繁中；英文环境 → 英文；其它语言 → 默认英文。菜单、HUD、提示文案语言一致。

### TC-L02 菜单内切换语言 【P0】
- **步骤**：点击右上角「简中 / 繁中 / EN」按钮。
- **预期**：菜单立即重建为对应语言；当前语言琥珀高亮 + 下划线；页面 `<html lang>` 与标题同步更新。

### TC-L03 对局内沿用所选语言 【P1】
- **前置**：菜单切换到英文后开始游戏。
- **预期**：HUD（Minerals/Vespene/Supply/Units/Selected）、操作提示、选中建筑后的面板按钮与标题、所有红字反馈均为英文。

### TC-L04 实体名称本地化 【P2】
- **步骤**：英文/繁中环境下悬停我方单位、打开训练面板。
- **预期**：悬停名签、面板按钮、提示中的单位/建筑名称为对应语言（如 Command Center / 指揮中心）；无翻译缺项时回落简中原名而非显示 key。

### TC-L05 数字插值正确 【P1】
- **步骤**：故意触发资源不足（如矿不够时点训练按钮）、能量不足（按 Y 大和炮能量不足时）。
- **预期**：红字提示包含正确的数字（如"Not enough minerals: need 50 (have 0)"），各语言均无 `{xxx}` 占位符残留。

## 3. 通用操作（三族）

### TC-G01 点选与框选 【P0】
- **步骤**：左键点单个单位；再拖拽框选一片单位。
- **预期**：点选最近者优先；框选只选己方单位（建筑不参与框选）；选中单位显示选中圈与血条；HUD 选中数同步。

### TC-G02 右键移动 【P0】
- **步骤**：选中单位后右键点空地。
- **预期**：单位沿寻路移动到目标点；地面单位绕开水面/悬崖。

### TC-G03 左键移动指令 【P1】
- **步骤**：有选区时左键点空地；无选区时左键点空地。
- **预期**：有选区 → 下达移动指令；无选区 → 清空选区。

### TC-G04 采集矿物与瓦斯 【P0】
- **步骤**：选中农民右键点水晶矿，等待往返数次；再右键点气泉。
- **预期**：农民自动往返采集，每次入账 8；瓦斯无需精炼厂（简化设定）可直接采集；HUD 资源数字增长。

### TC-G05 攻击指令 【P0】
- **步骤**：选中可攻击单位右键点敌方单位。
- **预期**：锁定攻击，弹道/命中特效播放，目标掉血；目标死亡后停止。

### TC-G06 攻击移动 A-Move 【P0】
- **步骤**：选中单位按 `A` 后左键点远处空地。
- **预期**：光标变化；单位前进途中自动攻击视野内敌人；`ESC` 取消瞄准态。

### TC-G07 编队 【P1】
- **步骤**：框选 3 个单位按 `Ctrl+1`；杀掉其中 1 个后按 `1` 召回；快速双击 `1`。
- **预期**：编队保存；召回时自动过滤死亡成员（剩 2 个）；400ms 内双击同键相机居中编队。

### TC-G08 运输机装载/卸载 【P1】
- **步骤**：选中运输机右键己方地面单位 ×N；按 `U` 卸载。
- **预期**：1.2 格内装载成功（乘客隐藏、不可被敌方锁定）；重型单位（坦克/雷车/巨人）占 2 位；`U` 环形落位卸载；运输机被毁乘客陪葬。

### TC-G09 ESC 取消语义 【P1】
- **步骤**：分别在建造放置、攻击移动、技能瞄准态按 `ESC`。
- **预期**：各自正确取消（幽灵建筑消失 / 光标恢复 / 瞄准态退出），面板关闭。

### TC-G10 相机操作 【P1】
- **步骤**：中键拖动、方向键滚动、小地图点击与按住拖动。
- **预期**：视野平滑跟随；小地图点击跳转、拖动连续平移；迷雾与实体点同步渲染。

## 4. 生产 / 建造 / 科技

### TC-P01 训练面板与队列 【P0】
- **步骤**：左键点指挥中心 → 面板点 SCV 按钮 ×6。
- **预期**：面板顶部显示「【指挥中心】点按钮下单」标题；前 5 个入队（上限 5），第 6 个红字拒绝「训练队列已满（5）」；资源即时扣减；完工后单位从建筑下缘出场。

### TC-P02 资源不足置灰与红字 【P0】
- **步骤**：矿耗尽后点训练按钮 / 打开建造面板。
- **预期**：买不起的按钮置灰（label 加 ×）；强行触发时红字提示需求数量与现有数量。

### TC-P03 科技门槛 【P1】
- **步骤**：无科技实验室时训练 ghost。
- **预期**：按钮置灰或红字「需要 科技实验室」；建成科技实验室后可正常训练。

### TC-P04 人口不足 【P1】
- **步骤**：把人口用满（如住房被拆）后继续训练单位。
- **预期**：红字「人口不足：需要 X（已用/上限）」；建供给站/水晶塔/训领主后恢复。

### TC-P05 建造放置合法性 【P0】
- **步骤**：选中农民按 `B`，分别尝试：正常地面 / 水面 / 悬崖 / 与既有建筑重叠 / 精炼厂不贴气泉 / 附属建筑远离主建筑。
- **预期**：幽灵建筑红绿实时反馈；非法位置左键无效；合法位置落子后农民前往施工（地基半透明 + 进度条，HP 从 10% 增长）。

### TC-P06 附属建筑挂接 【P1】
- **步骤**：SCV 在指挥中心 2.2 格内建卫星站；再尝试建第二座同类附属；在兵营旁建反应堆。
- **预期**：贴建合法（跳过重叠检查）；同类第二座拒绝；反应堆建成后训练速度 ×2；卫星站提供反隐。

### TC-P07 建筑死亡退款 【P1】
- **步骤**：兵营排队 2 个单位后用控制台/敌方攻击摧毁兵营。
- **预期**：队列中已扣费项目全额退回矿气；队列清空。

### TC-P08 科技升级 【P1】
- **步骤**：建成研究院/工程湾后选中，点攻击升级 Lv1；升到 Lv3 再点。
- **预期**：研究期间显示进度；完成后我方单位伤害 +2/级、受伤 -1/级（可用控制台断言 `attackDamage` 变化）；满级显示 MAX 且拒绝再研。

### TC-P09 虫族幼虫与变异链 【P0】
- **步骤**：虫族开局观察孵化场旁幼虫（≤3 只）；连续训练消耗幼虫；等待 12s 观察再生；面板执行孵化场→巢穴→母巢变异；菌毯殖民地→地刺堡/孢子堡。
- **预期**：无幼虫时训练红字拒绝；变异原位替换并保留当前 HP；变异中禁训练；地刺堡对地、孢子堡对空 + 反隐。

## 5. 三族特色机制

### TC-R01 坦克攻城模式 【P1】
- **步骤**：选中坦克按 `E`，再按 `E` 切回。
- **预期**：展开后射程/伤害提升（60 伤 / 12 格）、不能移动；切回恢复；展开状态下下达移动指令无效。

### TC-R02 兴奋剂 【P1】
- **步骤**：选机枪兵按 `T`。
- **预期**：自伤 10 HP、攻速/移速 ×1.5 持续 15s、淡红染色；增益期不重复生效；HP≤10 红字拒绝。

### TC-R03 碉堡进驻与聚合火力 【P1】
- **步骤**：步兵右键进驻碉堡 ×4（第 5 个拒绝）；敌接近观察开火；按 `U` 卸载；摧毁碉堡。
- **预期**：容量 4，满员红字；驻兵聚合开火（伤害求和、射程 +32px）；空堡不参战；卸载环形落位；碉堡被毁驻兵陪葬。

### TC-R04 隐形与反隐形 【P0】
- **步骤**：用 ghost/wraith 接近无侦测器的敌军；再在有导弹塔/光子炮/卫星站的区域重复；ghost 攻击一次；黑暗圣堂攻击一次。
- **预期**：无侦测器时敌方不能锁定/索敌到隐形单位；进入侦测网（7 格）即被锁定；ghost 攻击显形 2s，dt 攻击不显形；己方隐形单位半透明可见。

### TC-R05 锁定 Lockdown 【P1】
- **步骤**：ghost（能量 ≥100）按 `L` 点敌方坦克；再尝试锁 marine / 建筑 / 已锁定目标 / 超距目标。
- **预期**：坦克冻结 60s 蓝染（不索敌/不移动/不开火/不回能）；非机械/建筑/已锁/超距均红字拒绝且不扣能。

### TC-R06 核弹 【P1】
- **前置**：建成科学站（核弹前置），ghost 能量足够。
- **步骤**：按 `N` 指定落点；引导中移动 ghost / 杀 ghost；引导完成观察爆炸；30s 内再按 `N`。
- **预期**：落点显示红圈准星 + 倒计时；600 伤 3 格溅射敌我通吃（中立资源豁免，神族盾先扣）；ghost 位移/死亡打断引导（冷却不退）；装填期红字显示剩余秒数。

### TC-R07 大和炮 【P1】
- **步骤**：战列巡洋舰（能量 ≥150）按 `Y` 点敌方神族单位。
- **预期**：蓝光柱特效；250 伤穿盾（神族护盾不掉、直接扣血）；能量精确扣 150；能量不足红字。

### TC-R08 布雷 【P2】
- **步骤**：雷车按 `M` ×4；敌方地面单位接近地雷；己方单位走过雷区。
- **预期**：前 3 次成功（携雷 3 颗不补充）第 4 次拒绝；敌触即爆 100 伤 AoE；己方不触发；敌方雷对玩家隐形。

### TC-R09 灵能风暴 【P1】
- **步骤**：高阶圣堂（能量 ≥75）按 `S` 点落点。
- **预期**：3 波 ×20 伤 AoE，敌我通吃、不伤建筑；超 9 格不可落点；`ESC`/右键取消。

### TC-R10 精神控制 【P1】
- **步骤**：黑暗执政官（能量 ≥150）按 `C` 点敌方单位；再点建筑。
- **预期**：目标永久策反（变色、清指令、可操作）；建筑红字拒绝；人口重算正确。

### TC-R11 航母拦截机 【P2】
- **步骤**：训练航母（出厂带 4 架）；选中航母补造拦截机至 8；指派攻击；击毁航母。
- **预期**：拦截机自动出击/回收；机库满 8 拒训；拦截机不可被点选、停泊时不可被锁定；航母被毁拦截机全部陪葬。

### TC-R12 SCV 修理 【P2】
- **步骤**：受伤坦克/建筑旁右键（用 SCV）。
- **预期**：贴身按 35 HP/s 回血；满血自动收工；虫族农民不能修理。

### TC-R13 medic 自动治疗 / scourge 自爆 【P2】
- **步骤**：medic 放在受伤单位旁静置；scourge 撞向敌方空军。
- **预期**：medic 空闲自动治疗 6 格内友军（绿色光束），手动指令优先；scourge 引爆 110 伤与目标同亡。

## 6. 战斗与索敌

### TC-B01 待命迎击与受击反击 【P0】
- **步骤**：己方单位静置，敌人进入 6 格视野；再主动攻击一名静置单位。
- **预期**：待命单位自动迎击视野内敌人，目标死亡即回待命；受击者自动反击（农民除外）；移动中的单位不主动索敌。

### TC-B02 对空/对地类型 【P1】
- **步骤**：用仅对地单位（坦克）攻击空军；用女武神攻击地面单位。
- **预期**：无法攻击的目标不会被选为攻击对象（不白打）。

### TC-B03 神族护盾 【P1】
- **步骤**：攻击神族单位至护盾归零再继续攻击；静置观察脱战后的神族。
- **预期**：先扣盾再扣血；脱战后护盾缓慢恢复。

### TC-B04 战争迷雾 【P0】
- **步骤**：观察未探索区域（纯黑）→ 派单位探路 → 撤走单位。
- **预期**：三态切换（未探索黑 / 已探索暗 0.45 / 可见正常）；迷雾外敌方实体隐藏、不可点选/指定；探开区域保留暗色记忆。

### TC-B05 胜负判定 【P0】
- **步骤**：控制台速杀全部 AI 阵营 → 观察横幅；另一局速杀全部己方单位。
- **预期**：全灭 AI → 金色「胜利」横幅；玩家全灭 → 红色「失败」横幅；横幅后 AI 停摆但玩家仍可操作/观察。

### TC-B06 AI 经济与进攻 【P1】
- **步骤**：开局静置观察 2~3 分钟（可用控制台查各阵营资源/单位数）。
- **预期**：AI 采集增长、补农至 8、补人口、建产能建筑、持续出兵；AI 阵营间也会互相攻击（FFA）；农民不会放弃采集去追杀敌人。

## 7. HUD 与界面

### TC-H01 HUD 数据正确 【P0】
- **步骤**：对照控制台实际值检查矿物/瓦斯/人口（已用/上限）/我方单位数/选中数。
- **预期**：HUD 五项数字与实际状态一致；训练扣费、采集入账即时刷新。

### TC-H02 悬停名签 【P2】
- **步骤**：鼠标悬停我方单位/建筑、中立资源、敌方单位。
- **预期**：我方+中立显示头顶名称（含建造中标记）；敌方不显示名签（防迷雾泄密）；实体移动/滚屏时名签跟随。

### TC-H03 提示文本自动淡出 【P2】
- **步骤**：触发任意红字提示。
- **预期**：提示出现后自动淡出，不常驻。

## 9. 战网真人对战（server/，需先启动服务器）

> 前置：`cd server && npm run build-and-start`（或 IDE 运行任务「启动服务器」）；本机 MySQL 可用；客户端 `http://localhost:5173` 开两个标签页（A 端/B 端）。控制台断言：`window.__GAME__.scene.getScene("game")` 读 `isNetGame/isNetHost/entities.length/gameOver`。

### TC-N01 服务器启动 【P0】
- **步骤**：运行任务「启动服务器」，观察终端；再点「停止服务器」。
- **预期**：启动输出 `[db] MySQL 初始化完成`、`[http] 监听 :8100`、`[ws] 监听 :8101`、`server ready`（日志实时滚动）；停止输出 `已停止服务器进程 PID=…` 且进程确已结束。

### TC-N02 注册与登录 【P0】
- **步骤**：A 端战网面板：非法用户名注册（1 位/超 16 位）→ 合法注册（如 testp1/123456）→ 重复注册同名 → 正确登录 → 错误密码登录。
- **预期**：非法用户名/重复注册提示错误；注册成功自动进入已登录态；错误密码报"用户名或密码错误"，正确登录显示用户名与房间列表。

### TC-N03 建房与加入 【P0】
- **步骤**：A 端创建 1v1 房间 → B 端登录后在列表看到该房并加入 → A 端再开第三端加入 → B 端离开。
- **预期**：房间列表实时出现/人数更新/满员后不可再进；双方房间面板同步显示成员；A 端离开后 B 端成为房主；全员离开房间从列表消失。

### TC-N04 阵营与开局校验 【P0】
- **步骤**：1v1 房间双方同队 → A（房主）点开始 → 换边使 A/B 各 1 人 → 再点开始。
- **预期**：同队时提示"人数未对等"且不开局；对等后开局，全员（含 B 端）自动进入游戏场景。

### TC-N05 快照同步（镜像渲染） 【P0】
- **步骤**：开局后主机端停留 3 秒再切到镜像端，等待 3 秒。
- **预期**：镜像端地图/双基地/单位/HUD 正常渲染（`entities.length > 0`、`isNetGame=true`、`isNetHost=false`）；即使主机端已切后台（RAF 冻结）镜像端仍有实体（快照 setInterval 兜底 + lastSnapshot 补放）。

### TC-N06 指令同步 【P1】
- **步骤**：镜像端框选己方单位 → 右键移动 → 建造/出兵面板操作；对比主机端对应实体行为。
- **预期**：镜像端指令经服务器转发后在主机模拟中生效，快照回传后镜像端画面随之变化；镜像端无法操控他人单位（owner 校验）。

### TC-N07 正常结算与落库 【P0】
- **步骤**：一局打到一方阵营全灭（可用控制台辅助速杀）→ 双端观察横幅 → 查库 `SELECT * FROM battles ORDER BY id DESC LIMIT 1` 与 `SELECT wins,losses FROM users WHERE username IN (…)`。
- **预期**：双端显示胜利/失败横幅；battles 新增一行（room_id/队伍 uid/winner/时长）；胜方 wins+1、负方 losses+1。

### TC-N08 断线判负 【P0】
- **步骤**：对局进行中直接关闭镜像端标签页 → 主机端等待；再开一局关闭主机端标签页 → 镜像端等待。
- **预期**：存留端收到 player_left 并在数秒内出胜负横幅（对方判负）；战报落库 winner 正确；房间销毁。

### TC-N09 重复登录踢下线 【P2】
- **步骤**：同账号在第三个标签页登录同一战网账号。
- **预期**：旧连接收到"账号在其他窗口登录"并断开；新连接可正常操作（对局中断线按 TC-N08 判负）。

### TC-N10 单机回归 【P0】
- **步骤**：不起服务器（或不起战网），主菜单正常开一局单机 AI 战。
- **预期**：单机模式完全不受战网改动影响（`isNetGame=false`）；菜单「开始游戏」行为与泛化前一致。

### TC-N11 服务器冒烟脚本 【P1】
- **步骤**：服务器运行中执行 `cd server && node test/smoke.js`。
- **预期**：13 项断言全部 PASS（注册登录/建表/房间/加入/自动分队/对等校验/start_game 槽位/cmd 转发/snapshot 转发/game_over）。
