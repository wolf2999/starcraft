# 开发进度 —— 实体行为实现情况

> 统计基准：`src/config.ts`（实体定义）+ `src/entities.ts`（行为内核）+ `src/scenes/GameScene.ts`（指令/系统层）。
> 数据共 **91 个实体定义**：人族 20 建筑 + 13 单位，神族 12 建筑 + 15 单位，虫族 16 建筑 + 13 单位，中立资源 2。
> 地图（Lost Temple）实际出场：玩家虫族、AI 人族 ×3、AI 神族 ×2、AI 虫族 ×2（8 阵营 FFA）。

## 一、总体结论

| 层面 | 状态 |
|------|------|
| 通用战斗/移动/采集内核 | ✅ 基本完成 |
| 种族特色机制 | ⚠️ 仅护盾（神族）、菌毯/幼虫（虫族，部分） |
| 生产系统 | ❌ 未实现（`produces`/`buildTime` 只在 config 定义，无任何消费代码） |
| 建造系统 | ❌ 未实现（农民无法造建筑） |
| 技能/特殊能力 | ❌ 全部未实现（隐形、治疗、运输、法术、变形等） |
| AI | ⚠️ 仅阵营划分 + 主动索敌开关（`AI_AGGRESSIVE=false` 时完全被动），无经济/建造/生产 |

> 所有实体当前的行为上限 = "能被选中、能移动、能攻击（若有伤害数值）、能被攻击、能采集（限农民）"。
> 建筑的行为上限 = "站着挨打 + 人口供给（+防御建筑可攻击）"。**任何建筑都无法生产单位。**

### ✅ 已实现
| 系统 | 说明 | 代码位置 |
|------|------|----------|

| 战斗 | 对地/对空伤害区分（groundDamage/airDamage）、射程、攻击间隔、主动索敌 | entities `updateCombat` |
| 攻击指令 | 右键点击敌人 → `orderAttack` | GameScene `commandRightClick` |
| 采集 | 右键点矿/气泉 → 采集循环（去→采 1.5s→运回→入账 8）；**瓦斯无需精炼厂（简化）** | GameScene `updateGather` |
| 护盾（神族） | 先扣盾后扣血；0.7s 回 1 点再生 | entities `takeDamage` + GameScene update |

| 程序化贴图 | 三族各有美术风格（人族金属/神族水晶/虫族甲壳） | Textures.ts |
| 特效 | 攻击弹道线+命中爆点；死亡红光+建筑碎裂 | GameScene `drawShot/spawnDeathFx` |
| 选中表现 | 选中圈（空军扁椭圆）、血条/盾条 | entities `drawHpBar/drawSelectionRing` |

| 系统 | 说明 |
|------|------|

| 技能 | 隐形/反隐形、兴奋剂、治疗、运输装载、布雷、攻城模式、法术（风暴/大和炮/核弹/精神控制）全部缺失 |
| 装载类 | 碉堡进驻、运输机装兵、航母拦截机（`interceptor` def 存在但无装载逻辑） |
| 隐形体系 | 无隐形/反隐形判定（`turret/spore/cannon` 的"反隐"描述未生效） |
| AI 经济 | AI 不会采集/建造/生产，`AI_AGGRESSIVE=false` 时 AI 完全静止 |
| 其他 | 战争迷雾、编队（Ctrl+#）、热键面板、胜负判定、虫族死亡血泊 |

## 六、已知问题 / 小瑕疵

1. **零伤害单位**：`ht`（高阶圣堂）、`carrier`、`arbiter`、`darkarchon`、`medic` 数值上无法造成任何伤害，也没有替代行为——选中后只能移动。
2. **nexus 挂幼虫**：`LARVA_PRODUCERS`（config.ts:482）把 nexus 也算进去，神族主基地旁会出现 3 只虫族幼虫。
3. **defiler 误标 `air: true`**（config.ts:454），寻路会按空军直线飞行。
4. **AI 完全被动**：`AI_AGGRESSIVE=false`（config.ts:72），AI 不会索敌也不会移动；即使打开，AI 也没有经济与生产，只是"会走路的靶子"。
5. **瓦斯采集无前置**：任何农民右键气泉即可采气，精炼厂/吸收器/萃取器形同虚设。
6. **人口仅统计玩家**：AI 阵营不消耗人口（无生产所以无影响，实现生产后需补）。

## 七、建议实现顺序（按依赖关系）

1. **生产系统**（消费 `produces`/`buildTime`）：选中建筑 → 面板/热键训练单位 → 扣资源扣人口 → 出生点出兵。这是打通"能玩"的最短路径。
2. **虫族孵化**： larvae 变异入口（点击幼虫/孵化场面板选兵种），复用生产系统的扣费与计时。
3. **建造系统**：农民 `orderBuild`（虫族消耗幼虫/工蜂、人神族农民定点放置 + 进度条），消费 `buildTime`。
4. **AI 经济**：AI 农民自动采集 + 定时造农/造兵，让 8 人混战动起来（打开 `AI_AGGRESSIVE`）。
5. **隐形/反隐形体系**：为 `ghost/wraith/dt/observer/lurker` 与三个防御塔补全。
6. **英雄技能与特殊机制**：治疗（medic）、运输装载、攻城模式、大和炮、自爆（scourge）等，逐个补齐。
